1. Что такое HTML и теги

HTML — это язык разметки, задающий «скелет» сайта. Весь код состоит из тегов — команд в угловых скобках. Большинство тегов парные: открывающий <p> включает элемент, а закрывающий </p> со слэшем его выключает.

2. Базовый каркас файла

Любой HTML-файл начинается со строки <!DOCTYPE html>, указывающей браузеру версию HTML5. Далее идет главный контейнер <html lang="ru">, который обворачивает абсолютно все содержимое документа.

3. Раздел Head и Body

Код делится на две части: <head> содержит невидимые служебные настройки (кодировку, заголовок вкладки <title>, файлы CSS), а <body> хранит всё, что пользователь видит на экране.

4. Работа с текстом

Заголовки задаются тегами от <h1> (самый главный) до <h6> (самый мелкий). Обычный текст оборачивают в абзацы <p>. Чтобы выделить слово жирным, используют <strong>, а для курсива — <em>.

5. Ссылки и Изображения

Для создания ссылки используют тег <a href="адрес">. Изображения вставляются одиночным тегом <img src="путь" alt="описание">, где alt покажет текст, если картинка не загрузится.

6. Маркированные списки

Чтобы сгруппировать пункты, создают списки: <ul> (список с точками) или <ol> (нумерованный список 1, 2, 3). Каждую строку внутри оборачивают в отдельный тег <li>.

7. Контейнеры Div и Span

Тег <div> — это универсальная «коробка» для группировки крупных блоков страницы. Для выделения отдельного кусочка текста внутри строки используют строчный контейнер <span>.

8. Кнопки и Ввод данных

Формы собирают данные от пользователя. Поле <input type="text" placeholder="Имя"> создает строку для ввода текста, а тег <button>Отправить</button> делает кликабельную кнопку.
